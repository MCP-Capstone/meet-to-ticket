## v2.1 변경 내용 (2026-10-23)

- 신규 19개 요약본(과 원본회의록)에서 정답이 드러나는 제목과 문장을 수정
- v1의 ev31, ev32, ev41 ~ ev46 요약본과 정답을 병합. 본문과 정답은 그대로 두고, 요약본의 회의 ID 줄만 바꿈 (아래 참고)
- `중복판단_시드이슈.md` 추가 (ev41 ~ ev46 대조 저장소 `MCP-Capstone/meet-to-ticket-eval` 시드 #1 ~ #8)
- 명단은 v2 패키지의 `members.json`(6명, 가짜 로그인명, 함주헌 미연결) 사용

- 버전이 다르면 점수를 직접 비교하지 않는다.

## v2.1 추가 수정 (2026-10-23)

- 요약본 머리말의 회의 ID가 문항 이름(예: ev29_prompt_injection, ev41_same_open)을 드러내서, 27개 요약본(ev11 ~ ev46)의 회의 ID를 `MTG-번호`로 바꿈. 대응은 `회의ID_대응표.md` 참고
- 신규 19개 요약본의 "원본 회의록" 링크 줄 삭제 (파일명이 문항 이름이라 정답 단서가 됨)
- ev16: "민규가 두 명이라 다시 확인하기로 했다" 문장을 "담당은 \"민규님\"이 맡는 것으로 이야기가 끝났다"로 변경
- ev23: "한 건으로 정리했다" 문장 삭제
- ev26: 표의 완료 조건을 10min_1 요약과 같은 정보로 맞추고 배경 구간 추가 (형식만 다른 대조 문항이 되도록)
- 파일 이름과 정답 파일은 그대로라 채점 스크립트(결과 파일 이름 기준)에는 영향 없음
- Agent 파서(`agent/parsing.py`)로 30개 요약본 모두 회의 ID, 날짜, 제목을 읽는 것 확인
