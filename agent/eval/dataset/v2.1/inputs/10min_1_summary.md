## [구간 1] 요청 배경과 범위
원본 위치: 00:00~01:00

세 고객사의 요청에 따라 관리자 사용자 목록 CSV 내보내기를 공통 기능으로 제공한다. 접수 시점의 검색어/계정 상태 필터/정렬을 전체 결과에 적용한다. 컬럼은 이름/이메일/부서/계정 상태/가입일/마지막 로그인 일자이며 최대 5만 건이다. 초과하면 일부를 잘라 제공하지 않고 고객지원 문의를 안내한다. 23일 11시 배포는 QA와 보안 검토 통과가 전제인 목표다.

## [구간 2] API와 생성기
원본 위치: 01:30, 02:30, 05:30

박종민은 CSV-01로 API 계약을 19일 공유하고 비동기 접수와 CSV 생성기를 20일까지 구현한다. 작업 ID 반환 후 상태 API에서 완료 파일 URL을 제공한다. 조직 ID/요청자 ID 조합당 진행 중 작업은 하나이며 겹치는 요청에는 409와 진행 중 작업 ID를 반환한다. 다른 조직의 작업은 동시에 허용한다. UTF-8 BOM/표준 escaping/안전한 파일명을 적용하고 0건도 여섯 컬럼 헤더를 포함한다.

## [구간 3] 화면과 UX
원본 위치: 02:00, 03:30

임나윤은 CSV-03으로 내보내기 버튼/로딩/자동 다운로드/실패 재시도 화면을 19일 오후까지 구현한다. 최윤경은 별개의 CSV-04로 로딩/성공/실패/중복 요청/빈 결과 안내 문구와 키보드 접근 기준을 19일까지 정리한다. 빈 결과는 정상 다운로드로 안내한다.

## [구간 4] 권한과 감사 기록
원본 위치: 04:00~04:30

강민규는 CSV-02로 조직 관리자 권한 검사와 감사 로그를 20일 오전까지 구현한다. 조직 ID/요청자 ID/필터/건수/성공 여부를 기록하고 이름/이메일/CSV 본문은 제외한다. 세분화 권한과 역할 설정 화면은 범위에서 제외한다.

## [구간 5] 저장과 만료 검증
원본 위치: 06:00~06:30

함주헌은 CSV-05로 user-export/ 경로의 24시간 삭제/접근 권한/10분 서명 URL 만료를 20일 오후까지 검증한다. URL 발급 시 요청자와 조직 권한을 확인하며 파일 삭제와 URL 만료 증빙을 각각 남긴다. 다른 보고서의 7일 보관 정책에는 영향을 주지 않는다.

## [구간 6] 테스트 자료와 QA
원본 위치: 05:00, 07:00

허민규는 CSV-06으로 쉼표/큰따옴표/줄바꿈/이모지/빈 부서/탈퇴 계정을 포함한 테스트 사용자 20명을 19일 퇴근 전까지 준비한다. example.test 이메일을 쓰고 실제 개인정보는 사용하지 않는다. CSV-07로 22일 14시까지 통합 QA를 진행해 결과와 남은 결함을 기록한다. 나머지 다섯 명은 협조하며 필터/빈 결과/중복 클릭/비관리자 계정/URL 만료를 확인한다.

원본 위치: 08:00~08:30

다운로드 이력 화면과 알림은 권한/보관 요구가 미정이라 구현에서 제외한다. 회의에서 결정한 업무는 검토/승인 후 신규 발행한다.
