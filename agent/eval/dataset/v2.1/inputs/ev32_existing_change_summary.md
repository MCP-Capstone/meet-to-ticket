- 회의 참여자: 최윤경, 허민규

## [구간 1] API 진행 상황

최윤경은 대용량 요청에서 작업 상태가 늦게 갱신되는 문제로
기존 API 업무가 지연됐다고 설명했다.
담당자와 구현 범위는 유지하고, 기한을 내일 오후 6시로
옮기기로 합의했다.

## [구간 2] 빈 결과 오류

필터 결과가 0건이면 헤더만 있는 CSV가 내려와야 하지만
현재는 500 오류가 발생한다.
최윤경이 내일 오후 5시까지 수정하고 0건/1건 결과를
확인하기로 했다.

## [구간 3] 테스트 데이터

허민규는 기존 테스트 사용자 자료를 그대로 사용할 수 있다고
설명했다. 추가 데이터 제작이나 담당자 변경 요청은 없었다.

## [구간 4] 다운로드 이력 화면

이력 화면에 대한 의견이 나왔지만, 권한과 보관 방식이 정해지지
않아 이번 구현에서는 제외하기로 했다.
