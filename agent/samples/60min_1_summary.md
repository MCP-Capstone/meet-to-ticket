# 회의 요약 — 대형 고객 출시 준비와 멀티리전 전환 계획

## 배경 및 논의 요약

북미와 한국에 법인을 둔 대형 고객 한빛글로벌이 12월 14일 전사 도입을 요청했다. 데이터 지역성, SSO, 대량 문서 이관, AI 검색 품질, 장애 복구, 관리자 교육을 동시에 충족해야 한다. 별도 PM이 없어 여섯 명의 개발팀이 범위와 순서를 직접 조율한다.

회의는 12개 세부 안건을 5분 단위로 검토했다. 각 안건에서 현재 상황과 근거, 반대 의견, 보안·운영 제약, 성공 지표, 기존 이슈, 담당자·기한과 미결 질문을 확인했다.

## 핵심 결정

- 계약 요구사항과 출시 게이트: 11월 20일 데모, 12월 7일 100명 제한 운영, 12월 14일 전사 오픈의 세 게이트로 관리한다
- 한국·미국 리전 데이터 경계: 베타에서는 교차 리전 통합 검색을 제외하고 관리자는 리전을 선택해 조회하도록 한다
- 조직과 사용자 프로비저닝: 리전별 멤버십을 분리하되 동일 인물은 내부 person_id로 연결하고 화면에서 명시적으로 리전을 전환한다
- 180만 건 문서 이관 전략: 10만 건 파일럿 이후 일일 20만 건씩 이관하고 실패율이 2%를 넘으면 다음 배치를 자동 중단한다
- 검색 품질과 다국어 평가: 데모에 필요한 30개 교차 언어 질의만 승인된 평가셋으로 만들고 전체 기능 출시는 제한 운영 결과 뒤 결정한다
- 권한 기반 검색과 캐시: 제한 운영 전까지 권한 버전 캐시를 구현하고 성능이 부족하면 캐시를 끄더라도 보안을 우선한다
- 프론트엔드 리전 전환 경험: 첫 전환에만 설명 모달을 보이고 이후에는 명확한 배너와 로딩 상태를 제공한다
- 용량 계획과 비용 한도: 일일 비용 상한 6천 달러와 70·90·100% 알람을 설정하고 100%에서는 신규 배치만 멈춘다
- 장애 복구와 리전별 RTO: 동일 리전 내 다중 가용 영역 복구로 RTO를 맞추고 리전 간 복제는 하지 않는다
- 운영 모니터링과 고객 상태 페이지: 내부 알람 후 15분 내 영향 평가, 20분 내 승인된 첫 공지라는 운영 기준을 둔다
- 지원·교육·런북 인수: 기능 동결 버전을 기준으로 교육하고 변경분은 릴리스 노트로 보완한다
- 최종 일정·의존성·중단 기준: 월·수·금 비동기 상태 갱신과 화·목 15분 차단 요소 회의를 운영하며 11월 27일 최종 출시 판정을 한다

- 검색 품질과 다국어 평가: 일본어 품질이 기준에 못 미칠 때 일본어 문서를 출시 범위에서 뺄지
- 권한 기반 검색과 캐시: 대규모 그룹 변경 때 캐시 무효화가 완료되기 전 요청을 어떻게 처리할지
