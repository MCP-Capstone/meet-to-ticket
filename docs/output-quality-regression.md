# 출력 품질 보완 회귀 점검

이 점검은 GitHub 티켓·Slack 공지의 형식을 바꿀 때, 회의록 근거와 중복 판정 결과가 화면과 발행문에서 빠지지 않는지 확인하는 보완 장치다. 공식 평가셋 v2.1의 정답, 목표값, baseline 파일은 변경하지 않는다.

## 확인 범위

- 회의록 인용이 원문에 실제로 있는지
- 외부 참고자료가 등록된 문서 제목·링크인지
- 완료 조건이 비어 있거나 단순한 '검토한다' 같은 모호한 문구만 쓰이지 않는지
- 열린 SAME은 LINK, 열린 CHANGE는 UPDATE로 이어지는지

실행: cd agent && python -m pytest -q tests/test_output_quality_regression.py

이 검증은 고정 사례의 구조·계약 검사다. LLM이 실제 회의록에서 요구사항을 얼마나 정확히 추출했는지, 중복을 얼마나 잘 판단했는지의 성능 수치가 아니다. 그 평가는 이전과 같이 python -m eval.run_eval --runs 3으로 v2.1 전체를 실행해 #266의 baseline과 비교한다.

실제 외부 발행의 필드 정확도·중복 발행 수·처리 시간은 #303의 E2E 범위에서만 측정한다. 이 문서의 테스트는 외부 시스템에 쓰지 않는다.
